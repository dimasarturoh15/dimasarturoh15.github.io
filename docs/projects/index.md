## Cara menambah proyek baru

1. Salin `template.md` menjadi file baru, misalnya `nama-proyek.md`.
2. Isi semua bagiannya.
3. Daftarkan halaman itu di bagian `nav` pada `mkdocs.yml`.
4. Tambahkan satu baris di tabel di atas.
